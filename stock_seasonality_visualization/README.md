📈 Stock Market Seasonality & Return Visualizer
A quantitative finance project built with Python to analyze and uncover seasonal trends in stock market returns.

By restructuring historical price data,
this tool overlays multi-year performance onto a single chart to spot recurring market patterns,
monthly momentum, and historical anomalies across different years.

✨ Key Highlights
📥 Live Financial Data Retrieval: Automatically fetches historical market data using yfinance.

📊 Seasonal Pattern Extraction: Transforms raw closing prices into daily simple returns and maps them by month and year.

🎨 Advanced Visual Analytics: Uses Seaborn statistical plotting to layer multiple years for instant visual comparisons.

💡 Quantitative Insight: Helps identify structural market behaviors such as Q4 rallies or specific monthly pullbacks.
