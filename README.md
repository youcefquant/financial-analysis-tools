# 🛠️ Financial Analysis Tools & Quantitative Scripts

A comprehensive collection of Python scripts and quantitative finance tools developed for fetching, analyzing, and visualizing financial time series data. 

This repository serves as a personal codebase and sandbox for practical financial engineering concepts, mathematical models, and quantitative trading fundamentals.

---

## 📌 What’s Inside?

This project includes implementations for key quantitative techniques:

* 📡 **Financial Data Pipeline:** Automated fetching of historical market data using `yfinance` and public APIs.
* 📐 **Returns Calculation Methods:**
  * **Simple Returns:** Measuring percentage price changes over time.
  * **Logarithmic (Log) Returns:** Time-additive returns calculation for robust continuous compounding models.
* 📉 **Volatility & Risk Analysis:** Computing statistical measures like standard deviation and historical volatility.
* 🗓️ **Seasonality Analysis:** Multi-year overlay plots using `Seaborn` to inspect recurring calendar trends and monthly momentum.
* 📊 **Time Series Visualization:** Advanced plotting techniques for returns, price dynamics, and distribution analytics.

---

## 🧰 Tech Stack

- **Language:** Python 3.x
- **Data Manipulation:** `pandas`, `numpy`
- **Visualization:** `seaborn`, `matplotlib`
- **Data Retrieval:** `yfinance`

---

## 🎯 Purpose & Goals

To bridge theoretical quantitative finance concepts with practical Python implementation—building a modular toolkit for market data analysis, risk management, and algorithmic backtesting foundations.
